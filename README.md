# Worklife — общая база работодателей

Здесь хранится общая копия подписанных сведений о компаниях для [Worklife](https://github.com/dzenlotus/worklife-agent).
Приложения участников автоматически получают snapshot.json, проверяют авторские подписи и сохраняют локальные копии.

В базе только работодатели: компании, источники вакансий, условия и процесс найма. Профили работников,
CV, личная переписка, аккаунты и результаты персональных экспериментов не принимаются.

Изменения передаются приложением как подписанные события. Автоматический обработчик проверяет подписи,
цепочки и схему перед включением события в общий снимок. Исправления и отзывы добавляются новыми событиями.
Транспортные заявки в Issues служат машинному обмену; произвольные обсуждения не становятся данными базы.

Подпись подтверждает происхождение записи, а не правдивость утверждения о компании. Локальные проверенные
архивы позволяют обнаруживать и восстанавливать повреждение или откат общей копии. Сам GitHub не является
распределённым консенсусом: независимые локальные копии участников и сохранность их ключей остаются необходимыми.
